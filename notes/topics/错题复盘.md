# 错题复盘：从 LC 150 到 LC 636 的反复错误

> 复盘对象：LeetCode 150《逆波兰表达式求值》 + LeetCode 636《函数的独占时间》（共 3 个版本）。
> 目的不是"认错"，而是找出**反复出现的模式**，把它变成提交前的检查动作。

---

## 一、错误总清单（按性质分类）

### A 类：字符串解析 —— 4 次踩坑，同一个根因

| # | 题目 | 我写的 | 实际拿到 | 现象 |
|---|---|---|---|---|
| A1 | LC 150 | `(int)tokens[i][0]` | `'2'` → **50** | 压进栈的是 ASCII，`"23"`/`"-11"` 报废 |
| A2 | LC 636 v1 | `(int)logs[i][0]` | `'0'` → **48** | `root[48]` 越界 → **ASan `heap-buffer-overflow` 17:31** |
| A3 | LC 636 v1 | `(int)logs[i][8]` | ASCII + 越界 | 时间戳静默变成垃圾；`"1:end:5"` 只有 7 字符还越界读 |
| A4 | LC 636 v1 | `logs[i][2]` | 写死下标 | 编号 ≥ 10（`n ≤ 100` 合法）时读到 `':'`，被当 `end` |
| A5 | LC 636 v2 | `pd == "start"` | 比的是**地址** | `char[16]` 退化成指针，恒 false → 全走 else 分支 |

**根因一句话**：把**字符串**当成**数组**用，把**字符**当成**数字**用，把**数组名**当成**字符串**用。

- 字符串是「字符的序列」：取哪一段要先 `find` 定位，再 `substr` 切分，最后 `stoi/stoll` 整段转换；
- 字符 → 数字的**唯一**桥梁是 `c - '0'`，且只能处理**一位**；
- `char[]` 不是 `string`：`pd == "start"` 比的是两个地址，永远 false（**只是 warning，编译能过**）。

### B 类：容器与边界 —— 同一个坑第 2 次踩

| # | 题目 | 位置 | 现象 |
|---|---|---|---|
| B1 | LC 150 | `a.back()`（空 vector） | ASan `heap-buffer-overflow`，读 `begin()-1` |
| B2 | LC 636 v1 | `root[top]`（下标非法） | ASan `16:27 / 17:31`，读 `int` 越界 |
| B3 | LC 636 v2 | `int top=stack.back();` 写在 `if` 外 | 空栈取栈顶 → 读 `data[-1]` → 又一次 ASan |

**根因**：隐含假设「栈顶永远存在」。而**栈空是合法场景**，至少两种：

1. 程序刚开始（第一条日志一定是 `start`，没有父函数可结算）；
2. 一个顶层函数结束、下一个顶层函数还没开始的**间隙**。

所以：`start` 分支必须先 `if (!st.empty())`，`top` 这类"只有 `end` 才需要"的变量就该写在 `else` 里。

### C 类：算法语义 —— 区间开闭没定型

| # | 我写的 | 正确 | 后果 |
|---|---|---|---|
| C1 | `start` 也 `+1`（`t - root + 1`） | `start` → `t - root`（半开 `[root, t-1]`） | 示例 1 `[4,4]`、示例 2 `[10]`、示例 3 `[9,1]`，不崩但 WA |
| C2 | `end` 后 `prev = t` | `end` 后 `prev = t + 1` | 时刻 t 被重复计一次 |

**钉死的记法**：**start 是抢班，end 是交班 —— 交班的人要把最后一秒干完。**
`start` 和 `end` 指向的时刻**都属于函数自己**，只有"函数之间的空隙"不属于任何人。

### D 类：工程习惯

| # | 问题 | 影响 |
|---|---|---|
| D1 | 变量名 `stack` / `size` 遮蔽 `std::stack` / `std::size` | 本题不炸，换题容易炸 |
| D2 | 拿"编译通过"当"逻辑正确" | `pd == "start"` 只有 warning，却能毁掉整个分支逻辑 |
| D3 | 不读 ASan 报告的**尾部**（allocation site / 区域字节数） | 少了最快的定位线索（4 字节区域 = 1 个 `int` = `stack`） |
| D4 | 靠"特殊处理第一条日志 + 初值 0"蒙对 | 首条日志时间戳 ≠ 0 就错（`["0:start:5","0:end:9"]` 会算成 10） |
| D5 | 不设计最小用例，直接跑长用例 | 崩了也看不出是"哪一类"输入触发的 |

## 二、三个元问题（比具体错误更值得记）

### 1. 「记录过」≠「掌握」

A1（LC 150 的 ASCII 坑）**已经写进笔记并标了 ✅ 已掌握**，结果在 LC 636 立刻又踩了一遍。
→ 结论：**看懂 / 记下来 都不是掌握，能不看笔记默写出来才是。**
→ 行动：每个知识点用"默写 + 换题验证"来检验，而不是只打勾。

### 2. 调试顺序是反的

我实际做的：先纠结算法 → 崩溃后继续猜 → 再改一处 → 再崩。
应该做的顺序：

```
① 让最小用例不崩（n=1，两条日志）
② 让题目三个示例全对
③ 再谈边界与优化
```

**ASan 报的是"第一处"越界，不是唯一一处。** 修完 B2 才暴露 C1，修完 A5 才看到 B3 —— 崩溃是分层的，一层一层剥。

### 3. 对"合法输入"的假设太强

我默认了：编号一位数、时间戳一位数、栈永不为空、首条日志从 0 开始、字段位置固定。
**这些约束题目一条都没给**（题目只给：`n ≤ 100`、`t ≤ 1e9`、日志按时间递增、有 start 必有 end）。

→ 行动：写完先问一句「**如果数据长到两位数 / 十位数、如果栈是空的，我这行还成立吗？**」

## 三、提交前自检清单（7 条，逐条打勾）

| # | 检查项 | 反例 | 正确写法 |
|---|---|---|---|
| 1 | 有 `(int)` 强转字符吗？ | `(int)s[0]` | `s[0] - '0'`（一位）或 `stoi(s.substr(...))`（多位） |
| 2 | 有写死的下标吗？ | `logs[i][8]`、`logs[i][2]` | `find(':')` 定位 + `substr` |
| 3 | 有 `char[]` 和字面量 `==` 吗？ | `pd == "start"` | `strcmp(pd,"start")==0` 或 `string(pd)=="start"` |
| 4 | 每个 `.back()` / `.top()` / `.front()` 前判空了吗？ | `int top=stack.back();` | `if(!st.empty()){...}`；只有 `end` 才取 `top` |
| 5 | 数据范围允许几位？ | 只取一个字符当编号 | `n ≤ 100` → 两位；`t ≤ 1e9` → 十位 |
| 6 | 区间是开还是闭？ | `start` 也 `+1` | `start`: `t-root`；`end`: `t-root+1` |
| 7 | 跑过最小用例了吗？ | 直接跑长用例 | `n=1, ["0:start:0","0:end:0"]` → `[1]` |

**ASan 三行读法**（下次直接照这个看）：

1. `file:line:col` —— 列号能精确到 token（这次是 `.back()`，上次是 `root[top]`）；
2. `READ/WRITE of size N` —— N = 元素字节数（4 = `int`），锁定容器类型；
3. 尾部 `located ... N-byte region ... allocated by std::vector<int>` —— 区域字节数 ÷ 4 = 容量，直接锁定是**哪个** vector。

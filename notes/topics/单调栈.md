# 单调栈（Monotonic Stack）

> 一句话：单调栈就是**用一个保持单调的栈，维护"还没找到答案的那批元素"**。
> 某个元素**被弹出**的那一刻，就是它遇到「第一个比它大 / 比它小」的元素的时候。

> 配套可运行代码：`monotonic_stack.cpp`（7 个模板 + 3 个暴力版 + 5000 组随机对拍）
> 栈家族前置阅读：`逆波兰表达式.md`、`函数独占时间.md`

---

## 一、什么时候该想到它（信号词）

题目里出现这些说法，八成就是单调栈：

| 题目说法 | 例子 |
|---|---|
| 右边第一个比它**大/小**的元素 | 739 每日温度、496/503 下一个更大元素 |
| 左边/右边第一个比它**矮/高**的 | 84 柱状图最大矩形、42 接雨水 |
| 以某个元素为**最值**的子数组个数 / 和 | 907 子数组最小值之和、2104 子数组范围和 |
| 一段"连续区间 + 越来越差就作废" | 901 股票价格跨度、1124 表现良好时间段 |
| 最大宽度坡、132 模式 | 962、456 |

**共同结构**：每个位置都在等"最近的、比它更优/更差的另一个位置"。

---

## 二、核心原理：为什么暴力 O(n²) 能被砍到 O(n)

### 栈里到底装了什么

> 栈里装的是**还没找到答案的候选**，而且它们的值是**单调**的。

以「下一个更大元素」为例，从左往右扫：

- 新来的元素如果比栈顶大 → 栈顶那个位置的答案就是它，**弹掉**（栈顶已经解决完了，一辈子不用再管）；
- 如果比栈顶小 → 它比栈里所有元素都小，只能先入栈**等着**。

关键点：**一个元素一旦被弹出去，就再也不会被用到**。
所以每个元素最多入栈一次、出栈一次 → 总操作 ≤ 2n → **O(n)**。

```
递减栈（栈底 → 栈顶 值递减）    来一个更大的 → 把比它小的全弹掉
    [ 75 ]                        [ 76 ]
    [ 72 ]        ← 来 76 →       （75、72 都解决了，出栈）
```

**"弹出即结算"** 是单调栈的统一心法。

## 三、写代码前的三要素

每次动笔前问自己三句话：

### ① 栈里存**下标**还是**值**？

| 需要什么 | 存什么 | 例子 |
|---|---|---|
| 距离 / 宽度 / 左右边界 | **下标** | 739（算天数差）、84（算宽度） |
| 只问"下一个更大是谁" | **值**即可 | 496、503 |

> 存下标的通用性更强（`nums[st.back()]` 随时能取回值），
> 但只要不需要位置信息，存值能让代码更短（496 就是）。

### ② 栈是**递增**还是**递减**？

| 想求 | 栈的方向（底→顶） | 弹栈条件（新元素 `x` 来了） |
|---|---|---|
| 下一个**更大** | 单调**递减** | `nums[top] < x` 就弹 |
| 下一个**更小** | 单调**递增** | `nums[top] > x` 就弹 |

记忆法：**"谁被弹，谁就找到了答案"**。
要找更大的，就得让"小的"先被弹掉 → 栈里从底到顶逐渐变小（递减栈）。

### ③ 弹栈用**严格**还是**非严格**？

`<` 还是 `<=`，决定**重复元素归谁**：

- 739（下一个更高温度）：`<`，相等不算"更高" ✅
- 1475（不大于它的价格就打折）：`>=`，相等也打折 ✅
- 907（贡献法）：**左边严格小于、右边小于等于** —— 一严一宽，否则相等的元素会被重复计数（见第六节）

## 四、五个模板

### 模板 A：下一个更大（739 / 496 / 503）

```cpp
// LC 739 每日温度：对每个 i，找右边第一个更高的位置 j，答案 j - i
vector<int> dailyTemperatures(vector<int>& T) {
    int n = T.size();
    vector<int> ans(n, 0), st;                 // 递减栈，存下标
    for (int i = 0; i < n; ++i) {
        while (!st.empty() && T[st.back()] < T[i]) {   // ★ 先判空！
            int j = st.back();
            st.pop_back();
            ans[j] = i - j;                    // 弹出即结算
        }
        st.push_back(i);
    }
    return ans;                                // 留在栈里的右边没有更高温度 → 保持 0
}
```

**逐帧演示**（`T = [73,74,75,71,69,72,76,73]`，这是理解单调栈最好的例子）：

| i | T[i] | 弹出并结算 | ans | 栈（底→顶） |
|---|---|---|---|---|
| 0 | 73 | — | `[0,0,0,0,0,0,0,0]` | `[0(73)]` |
| 1 | 74 | 弹 0：`ans[0]=1-0=1` | `[1,…]` | `[1(74)]` |
| 2 | 75 | 弹 1：`ans[1]=2-1=1` | `[1,1,…]` | `[2(75)]` |
| 3 | 71 | 不弹（71 < 75） | | `[2(75),3(71)]` |
| 4 | 69 | 不弹 | | `[2,3,4(69)]` |
| 5 | 72 | 弹 4：`ans[4]=1`；弹 3：`ans[3]=5-3=2`；72<75 停 | `[1,1,…,2,1,…]` | `[2(75),5(72)]` |
| 6 | 76 | 弹 5：`ans[5]=1`；弹 2：`ans[2]=6-2=4`；栈空 | `[1,1,4,2,1,1,…]` | `[6(76)]` |
| 7 | 73 | 不弹 | | `[6(76),7(73)]` |

结果 `[1,1,4,2,1,1,0,0]` ✅ —— 注意**一次 `while` 里可能连弹好几个**，这就是 O(n) 的来源。

**两个变体**：

```cpp
// LC 496：不需要距离 → 栈里直接存值
unordered_map<int,int> nxt;                    // 值 -> 它右边第一个更大的值
vector<int> st;
for (int x : nums2) {
    while (!st.empty() && st.back() < x) { nxt[st.back()] = x; st.pop_back(); }
    st.push_back(x);
}

// LC 503：循环数组 → 走两圈，只有第一圈入栈
for (int i = 0; i < 2 * n; ++i) {
    int cur = nums[i % n];
    while (!st.empty() && nums[st.back()] < cur) { ans[st.back()] = cur; st.pop_back(); }
    if (i < n) st.push_back(i);                // ★ 第二圈只用来"当别人的后继"
}
```

### 模板 B：左右边界 + 面积（84 柱状图最大矩形）

**思路**：枚举"以哪根柱子为矩形的高"，然后向两边扩到第一根比它矮的柱子为止。

```cpp
int largestRectangleArea(vector<int>& heights) {
    vector<int> h{0};                                  // ★ 左哨兵
    h.insert(h.end(), heights.begin(), heights.end());
    h.push_back(0);                                    // ★ 右哨兵

    vector<int> st;                                    // 递增栈，存下标
    int best = 0;
    for (int i = 0; i < h.size(); ++i) {
        while (!st.empty() && h[st.back()] > h[i]) {
            int height = h[st.back()];
            st.pop_back();
            int left = st.empty() ? -1 : st.back();    // 左边界（不含）
            best = max(best, height * (i - left - 1)); // ★ 宽度 = i - left - 1
        }
        st.push_back(i);
    }
    return best;
}
```

**为什么要两端加哨兵 `0`**：

1. 左哨兵保证**栈永远不为空** → 省掉所有 `st.empty()` 判断（你上次就是在空栈 `back()` 上崩的）；
2. 右哨兵保证**遍历结束时栈一定被弹空** → 不用再写"收尾"循环；
3. 高度 0 永远不会成为答案，不影响结果。

**宽度公式怎么来的**：
弹出栈顶 `t` 时，`i` 是右边第一个比它矮的，`st.back()` 是左边第一个比它矮的，
所以矩形只能铺在开区间 `(left, i)` 上 → 宽度 `i - left - 1`（栈空时 `left = -1`，宽度正好是 `i`）。

示例 `[2,1,5,6,2,3]`，加哨兵后 `[0,2,1,5,6,2,3,0]` 的两个关键结算：

| i | h[i] | 弹出并结算 | best |
|---|---|---|---|
| 5 | 2 | 弹 `6`：`left=3`，`w=5-3-1=1` → 面积 6；弹 `5`：`left=2`，`w=5-2-1=2` → 面积 **10** | **10** |
| 7 | 0 | 弹 `3`：`w=1` → 3；弹 `2`：`left=2`，`w=7-2-1=4` → 8；弹 `1`：`w=6` → 6 | 10 |

答案 `10` ✅（高度 5、宽度 2 的那个矩形）

### 模板 C：弹出时"按层"累加（42 接雨水）

**思路**：递减栈。当 `h[i]` 比栈顶高，栈顶就是**坑底**，它的左边界是新栈顶、右边界是 `i`，这一层的水横着加上去。

```cpp
int trap(vector<int>& height) {
    vector<int> st;                                    // 递减栈，存下标
    int water = 0;
    for (int i = 0; i < height.size(); ++i) {
        while (!st.empty() && height[st.back()] < height[i]) {
            int bottom = st.back(); st.pop_back();
            if (st.empty()) break;                     // ★ 左边没有更高的边 → 接不住
            int left = st.back();
            int w  = i - left - 1;                     // 这一层的宽度
            int hh = min(height[left], height[i]) - height[bottom];   // 这一层的水高
            water += w * hh;
        }
        st.push_back(i);
    }
    return water;
}
```

**按层理解**（`[0,1,0,2,1,0,1,3,2,1,2,1]` → 6）：
每一层的"桶"是 **左壁高、右壁高、底高** 三元组决定的，一层一层往上加，
所以**不会重复**（这正是 42 用单调栈容易写错的地方 —— 按"每个位置纵向算"会重复）。

### 模板 D：贡献法（907 子数组的最小值之和）

**思路转向**：不问"每个子数组的最小值是多少"，而问
**"arr[i] 是多少个子数组的最小值？"** → 贡献 = `arr[i] × left[i] × right[i]`。

```cpp
int sumSubarrayMins(vector<int>& arr) {
    const long long MOD = 1000000007LL;
    int n = arr.size();
    vector<int> left(n), right(n), st;

    for (int i = 0; i < n; ++i) {                       // 左边第一个"严格小于"
        while (!st.empty() && arr[st.back()] >= arr[i]) st.pop_back();
        left[i] = st.empty() ? i + 1 : i - st.back();
        st.push_back(i);
    }
    st.clear();
    for (int i = n - 1; i >= 0; --i) {                  // 右边第一个"小于等于"
        while (!st.empty() && arr[st.back()] > arr[i]) st.pop_back();
        right[i] = st.empty() ? n - i : st.back() - i;
        st.push_back(i);
    }

    long long ans = 0;
    for (int i = 0; i < n; ++i)
        ans = (ans + (long long)arr[i] * left[i] * right[i]) % MOD;   // ★ 先转 long long
    return (int)ans;
}
```

`arr = [3,1,2,4]` 的手算验证：

| i | arr[i] | left[i] | right[i] | 贡献 |
|---|---|---|---|---|
| 0 | 3 | 1 | 1 | 3 |
| 1 | 1 | 2 | 3 | 6 |
| 2 | 2 | 1 | 2 | 4 |
| 3 | 4 | 1 | 1 | 4 |

合计 `17` ✅（暴力枚举全部 10 个子数组也是 17）

**为什么必须一严一宽**：相等元素会被两个人都算成"最小值"。
左边用严格小于、右边用小于等于 ⇒ 相等的元素只归**最右边那一个**管，计数不重不漏。

### 模板 E（对比）：239 滑动窗口最大值 —— 这是单调**队列**

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;                                  // 存下标，值单调递减
    vector<int> ans;
    for (int i = 0; i < nums.size(); ++i) {
        while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();  // 尾部：小的没用
        dq.push_back(i);
        if (dq.front() <= i - k) dq.pop_front();    // ★ 头部：滑出窗口就出去
        if (i >= k - 1) ans.push_back(nums[dq.front()]);
    }
    return ans;
}
```

| | 单调栈 | 单调队列 |
|---|---|---|
| 两端操作 | 只在**一端**进出 | **尾部**入队 + **头部**出队 |
| 为什么能出队 | 元素被弹出就永不再用 | 窗口**左边界滑过**就失效 |
| 典型题 | 739 / 84 / 42 / 907 | 239 / 862（和最短路） |

## 五、常见错误清单（按踩坑频率）

### ❌ 错误 1：忘记判空，空栈 `back()`

```cpp
while (T[st.back()] < T[i])        // ❌ 第一次循环 st 就是空的
while (!st.empty() && T[st.back()] < T[i])   // ✅
```

**后果**：`heap-buffer-overflow, READ of size 4`（读 `data[-1]`）—— 这正是你 09-17 那次
`stack.back()` 崩溃的同款。**单调栈里每个 `while` 都要判空**，除非你像 84 那样加了哨兵。

### ❌ 错误 2：该存下标却存了值（或反过来）

要算 `i - j`（距离）、`i - left - 1`（宽度）时，**必须存下标**；
存了值就再也找不回位置，只能推倒重写。

### ❌ 错误 3：遍历结束后忘了"收尾"

栈里剩下的元素怎么办？

| 题 | 剩下的元素表示 | 处理方式 |
|---|---|---|
| 739 | 右边没有更高温度 | `ans` 初值 0，天然正确 |
| 496 | 右边没有更大的 | 不在 map 里 → 输出 -1 |
| 84 | 右边没有更矮的 | **右哨兵 0** 强制把它们弹掉 |
| 907 | 右边没有更小的 | `right[i] = n - i` 默认值 |

**要么用哨兵，要么想清楚默认值** —— 这是最容易漏的一步。

### ❌ 错误 4：递增 / 递减搞反

"找下一个更大"要**递减栈**（底→顶 递减）。
判断口诀：**栈里从底到顶，是被"更大的新元素"依次弹掉的一批候选**。

### ❌ 错误 5：`<` / `<=` 写错，重复元素出问题

- 739 用 `<`（相等不算更高）
- 1475 用 `>=`（相等也打折）
- 907 必须"左严格小于、右小于等于"

**遇到有重复值的题，先想清楚"相等时归谁"。**

### ❌ 错误 6：循环数组只走一圈

503 要么走 `2n` 取模（第二圈不入栈），要么把数组复制一遍接在后面。
**只走一圈**的话，末尾元素的"下一个"会漏。

### ❌ 错误 7：84 的宽度算错

```cpp
best = max(best, height * (i - left));        // ❌ 宽了 1
best = max(best, height * (i - left - 1));    // ✅
```

栈空时 `left` 要取 **-1**（不是 0），否则第一段宽度少 1。

### ❌ 错误 8：42 用"纵向"思路写单调栈

按层（横向）累加才不重复；若试图对每个位置单独算"左右最高"，那还不如直接用
前缀/后缀最大值数组（O(n) 空间，更好写）。

### ❌ 错误 9：907 的乘法溢出

`arr[i] * left[i] * right[i]` 最大约 `1e4 × 1e5 × 1e5 = 1e14`，
**`int` 一定溢出**，必须先转 `long long` 再取模。

### ❌ 错误 10：把 `?:` 当 `if` 用，且 `st.top` 少写括号

```cpp
(!st.empty()) ? a[i] : a[i] = st.top-i;      // ❌ 三个问题叠在一起
```

**① `st.top` 是成员函数名，不是值** → `st.top - i` 编译报错：

```
error: reference to non-static member function must be called
```

要写 `st.top()`。（若容器是 `vector`，根本没有 `top`，应为 `st.back()`。）
同理 `v.size()`、`v.back()` 的括号都不能省。

**② `?:` 是"表达式"，不是"语句"**。C++ 里 `?:` 的**第三操作数允许是赋值表达式**，
所以这句被解析成：

```cpp
(!st.empty()) ? a[i] : (a[i] = st.top() - i)
```

- 栈**不空** → 只求值了一下 `a[i]` 然后丢掉：**什么都不做**；
- 栈**空** → 反而去调 `st.top()`（空栈，UB）并赋值。

**逻辑正好反了**，而且它不是语法错误，顶多一条 warning —— 又是"能编译 ≠ 正确"。

**③ 方向反了**：距离是 `i - st.top()`（当前位置减栈顶下标），不是 `st.top() - i`。

```cpp
// ✅ 写法一：整个三元放在 = 右边（st.empty() 短路，安全避开空栈 top()）
ans[i] = st.empty() ? 0 : i - st.top();

// ✅ 写法二：老实写 while（739 的结算）
while (!st.empty() && T[st.back()] < T[i]) {
    int j = st.back(); st.pop_back();
    ans[j] = i - j;
}
```

> 顺带记住：`cond ? return a : return b;` 也是**语法错误** —— `return` 是语句不是表达式。
> `?:` 唯一可以"当 if 用"的正当场合，就是这种**惰性求值**：用它短路掉非法的空栈访问。

## 六、复杂度

| 项 | 复杂度 | 说明 |
|---|---|---|
| 时间 | **O(n)** | 每个元素入栈 1 次、出栈 ≤ 1 次，`while` 的弹栈总量是 O(n)（摊还分析） |
| 空间 | **O(n)** | 栈 + 答案数组 |

> **摊还（amortized）思想**：`while` 看起来可能弹很多次，但把整个循环加起来，
> 总弹出次数 ≤ 总入栈次数 = n。所以不是 O(n²)。

## 七、一句话记忆

> **单调栈 = 维护一批"还没找到答案的候选"，并让它们的值保持单调。**
> 新元素一来，把"被它解决掉"的候选弹出去 —— **弹出即结算**。
> 三要素：**存下标还是存值 · 递增还是递减 · 严格还是非严格**。
> 收尾别忘了：**要么两端加哨兵，要么想清楚剩下元素的默认值。**

## 📚 学习内容

### 主题一：GitHub Actions 的定时任务

- **是什么**：仓库里放一个 `.github/workflows/*.yml`，GitHub 就按 `on:` 里声明的条件（`schedule` / `push` / `workflow_dispatch`）在云端跑脚本。
- **关键点**：
  - `cron` 用的是 **UTC**。北京时间 00:00 要写 `0 16 * * *`，而不是 `0 0 * * *`。
  - 用仓库自带的 `GITHUB_TOKEN` 产生的推送**不会再触发**新的工作流，天然防止递归。
  - 工作流要往仓库里提交，必须显式声明 `permissions: contents: write`。
- **和已知知识的联系**：本质就是事件驱动的 CI，和「自己写个定时脚本」的差别只在于跑在别人机器上、且与 git 生命周期绑定。

### 主题二：OAuth token 的 scope

- **是什么**：`gh` 登录后拿到的 token 带一组权限位，默认**不含** `workflow`。
- **关键点**：只要提交内容里包含 `.github/workflows/` 下的文件，缺 `workflow` scope 就会被拒绝：

  ```text
  ! [remote rejected] main -> main (refusing to allow an OAuth App to
    create or update workflow `.github/workflows/notes.yml` without `workflow` scope)
  ```

- **怎么补**：`gh auth refresh --hostname github.com --scopes workflow`
- **教训**：报错信息里 `without 'workflow' scope` 已经把答案写出来了，别急着换方案，先读完整句。

## 💻 代码与实践

```powershell
# 1. 补 workflow 权限（会再走一次设备码授权）
gh auth refresh --hostname github.com --scopes workflow

# 2. 本机 github.com 直连不通，git 也要走代理
$env:HTTPS_PROXY = 'http://127.0.0.1:7892'
git config --local http.proxy http://127.0.0.1:7892

# 3. 从系统代理设置里读代理地址（省得每次手填）
(Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Internet Settings').ProxyServer
```

```yaml
# 每天北京时间 00:00 建当天的空白笔记
on:
  schedule:
    - cron: '0 16 * * *'   # UTC 16:00 == 北京 00:00
permissions:
  contents: write
```

## 🔍 难点与解决

| 问题 | 原因 | 解决办法 |
| --- | --- | --- |
| `winget` 报 `0x8A150001`，`curl` 报 `SEC_E_NO_CREDENTIALS` | 沙箱限制凭据库与出站网络 | 提权执行 |
| `api.github.com` 返回 200，`github.com` 连接超时 | 域名不通，而浏览器走了系统代理 | 从注册表读 `ProxyServer`，注入 `HTTPS_PROXY` |
| 推送被拒 `without 'workflow' scope` | token 权限位不够 | `gh auth refresh -s workflow` |
| `.cmd` 里的中文注释被当成命令执行 | cmd.exe 按 ANSI 解析 UTF-8 字节 | 批处理文件只用 ASCII |
| `note.cmd` 第一行 `@echo off` 失效 | 文件被写入了 BOM | 去掉 BOM |
| PowerShell 脚本报「缺少右 `}`」 | 中文与嵌套 `$()` 触发编码解析问题 | 改纯 ASCII，拆开字符串拼接 |

## ✅ 今日总结

- 自动化里最容易被忽略的两件事：**时区**（cron 是 UTC）和**权限**（token scope）。
- 排查网络问题要**逐层对比**：先分清「完全不通」还是「通但慢」，再横向比不同域名——`api.github.com` 通而 `github.com` 不通，就直接指向代理/墙，而不是「网络不好」。
- 批处理文件保持纯 ASCII，能省掉一整类编码玄学。
